# MALUT STORE CMS

## Versión
1.0

## Descripción

Sistema de administración del catálogo de Malut Store desarrollado con:

- HTML5
- CSS3
- JavaScript
- Google Sheets
- Google Apps Script

Toda la información del catálogo se administra desde Google Sheets.

No es necesario modificar el HTML para agregar productos.
